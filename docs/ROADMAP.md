# Reliability roadmap

The current application provides browser PDF tools, local English/Arabic OCR, structured reading and receipt layouts, editing, and local exports.

Next priorities:

- Evaluate OCR on varied real-world receipts, rotated scans, shadows, mixed languages, and imperfect photographs.
- Expand receipt layouts, currencies, integer-only prices, and multi-line item matching while retaining source text.
- Improve reading order for complex multi-column and right-to-left PDFs.
- Add Firefox/WebKit coverage and manual screen-reader and physical touch-device checks.
- Profile low-memory phones and improve cancellation during recognition engine initialization.
- Extend PDF preservation checks for forms, signatures, bookmarks, and unusual fonts.

This is a maintenance plan, not a list of inactive tools shown in the product.
